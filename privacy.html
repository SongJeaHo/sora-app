개인정보처리방침

시행일 2026년 11월 9일

SORA는 개발자 본인이 자기 Mac에서 쓰려고 만든 앱입니다. 이 방침은 SORA가 Google 계정 데이터를 어떻게 다루는지 설명합니다.

읽는 데이터

  • Gmail 메일(제목, 보낸 사람, 본문)과 계정의 보내는 주소 설정
  • Google Calendar 일정과 캘린더 목록

쓰는 곳

읽은 데이터는 사용자 Mac의 홈 폴더(~/.sora)에만 저장하고, 약속·마감·미팅 정리와 답장 초안 작성에만 씁니다. 메일 본문은 30일이 지나면 지웁니다. Gmail에 쓰는 동작은 사용자가 확인한 답장을 임시보관함 초안으로 저장하는 것 하나뿐이며 메일을 보내지 않습니다. 캘린더는 읽기만 합니다.

바깥으로 보내지 않는 것

SORA에는 서버가 없습니다. 데이터를 개발자나 다른 사람에게 보내거나 팔지 않고, 광고에 쓰지 않습니다. 요약과 초안을 만들 때 사용자 본인의 Claude 구독으로 해당 내용을 보낼 수 있으며, 사용자가 제외한 도메인과 주소의 메일 본문은 보내지 않습니다.

인증 정보

Google 새로고침 토큰은 Mac의 키체인에만 저장합니다.

삭제

SORA 설정에서 계정 연결을 끊거나 ~/.sora 폴더를 지우면 저장된 데이터가 모두 사라집니다. Google 계정의 보안 설정(타사 앱 액세스)에서 SORA의 접근 권한을 언제든 철회할 수 있습니다.

SORA가 Google API에서 받은 정보를 쓰고 다른 앱으로 옮기는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.
